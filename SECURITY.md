# Security Policy

## Scope & Purpose

`@gykh/cat-facts` is a small, offline library that returns bundled cat facts. It makes no network requests, reads no files and has no runtime dependencies.

## Reporting a Vulnerability

If you discover a vulnerability or denial-of-service issue (e.g. a crash, hang or unexpected behavior in the library or CLI), please report it responsibly by contacting:

* **Email**: sylvester.das@gmail.com
* **GitHub Issues**: https://github.com/get-your-knowledge-here/cat-facts/issues
