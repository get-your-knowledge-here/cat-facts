    Fun facts about cats

    Cats spend about two thirds of their lives asleep, can rotate their ears about 180 degrees, and have whiskers on the backs of their front legs. Every fact here was picked for being true and surprising; popular myths were left out.

    How to get a cat fact every day

    1. Bookmark this page and press Fact of the day. It changes at midnight UTC.
    2. In your terminal: run npx @gykh/cat-facts --today.
    3. On every new shell: npm i -g @gykh/cat-facts and add cat-facts to your ~/.zshrc or ~/.bashrc.

    Use it in your code

    Every fact on this page ships in a free, MIT-licensed, zero-dependency npm package with TypeScript types and a CLI. No API key, no network, no rate limits.

    npm install @gykh/cat-facts

import { randomFact, factOfTheDay, search } from "@gykh/cat-facts";
randomFact();     // "A group of cats is called a clowder."
search("purr");   // every fact about purring

    Frequently asked questions

    Where do these cat facts come from?

    They are a hand-curated list of well-established facts about cat biology, behavior, breeds and history. Popular myths and shaky statistics were left out.

    How does the cat fact of the day work?

    The fact is picked from the current UTC date, so everyone sees the same fact all day and a new one the next day. The npm package uses the same rule.

    Is there a cat facts API I can use in my code?

    Yes. Install @gykh/cat-facts. It bundles every fact, works offline with zero dependencies, and includes TypeScript types and a CLI.

    How do I share a cat fact?

    Press Share and send the link; it opens this page on the same fact. To get a short, tidy link and see how many people opened it, shorten it with MiniFyn.
